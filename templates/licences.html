Data sources and licences

Overlap ships with reference data it did not create. This page says where each piece came from, what its licence asks for, and what was changed.

City coordinates: GeoNames

Every city in an uploaded file is turned into a latitude and longitude using a table bundled with this tool, and that table is derived from the GeoNames geographical database, used under Creative Commons Attribution 4.0 International (CC BY 4.0).

It has been reduced and modified for this product. The bundled file is not the GeoNames database. It keeps city name, country code, latitude, longitude and population, drops every other column, drops smaller places, and is sorted by population so an ambiguous city name resolves to the largest place of that name. Nothing in it was corrected or invented: the rows that remain carry GeoNames' own values.

The file is data/cities.csv and the same attribution is in LICENSE in the repository, which is what travels with the code.

Emission factors: DEFRA and GLEC

Kilograms of CO2e per tonne-kilometre, per transport mode, follow published figures from the UK Government's DEFRA conversion factors and the GLEC framework. The figures used and the reasoning are in optimizer/factors.py, and the report prints every one of them under Data and assumptions rather than hiding them.

Cost factors: not sourced

The cost per tonne-kilometre for each mode is the author's own default, not a published dataset and not a carrier tariff. The tool says so wherever the figures appear, and your own rates replace them. This is the softest input in the tool and the reason it describes itself as a screen rather than a quote.

The example companies

Both sample datasets were invented for this project. They describe no real company, no real customer and no real shipment. Their figures are generated to follow realistic patterns so the tool behaves the way it would on a real network, and every page, print and export that shows them says they are not real.

Overlap itself

The application code is released under the MIT licence, copyright Edmond Badran. That licence covers the code and nothing else: the bundled GeoNames extract keeps its own CC BY 4.0 terms, which stay with the data wherever it goes, and the MIT grant does not relicense it.
