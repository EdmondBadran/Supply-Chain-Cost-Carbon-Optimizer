Five columns are enough origin_name origin_city dest_city weight_kg mode

Add a warehouse or supplier file
Which columns each file needs

Orders, required: origin_name, origin_city, dest_city, weight_kg, mode. Optional: order_ref (or order_id), order_date, customer_id, origin_country, dest_country, units, product_category, order_value, returned. Add origin_lat / origin_lon / dest_lat / dest_lon for anywhere too small for the city lookup.

Warehouses, optional: name plus storage_cost_annual, energy_kwh_annual, grid_intensity and capacity_kg. Give a site a capacity and closing its neighbour is tested against what it can really hold. Leave it out and an assumption stands in instead, which the result tells you it has used.

Suppliers, optional: name, city, supplies (the warehouse it feeds), mode and annual_weight_kg, plus country, shipments_per_year, annual_cost, lead_time_days, min_order_qty and on_time_rate. Add it and the chain runs end to end instead of starting at your warehouses.

Transport modes are road, rail, sea and air. Aliases like truck, ground, ship and plane are read as the right mode. City names can be spelled properly: Malmö and Jönköping resolve the same as Malmoe and Joenkoeping.
