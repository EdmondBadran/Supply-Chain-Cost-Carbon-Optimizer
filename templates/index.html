Use your own data

A CSV export of order lines. Anything it cannot read is reported by line number.

Which columns the orders file needs

Required: origin_name, origin_city, dest_city, weight_kg, mode.

Optional: order_ref, order_date, customer_id, origin_country, dest_country, units, product_category, order_value, returned. Add origin_lat / origin_lon / dest_lat / dest_lon for anywhere too small for the city lookup.

Transport modes: road, rail, sea, air. Aliases like truck, ground, ship and plane are read as the right mode.

The supplier file needs name, city, supplies (the warehouse it feeds), mode and annual_weight_kg, plus optional country, shipments_per_year and annual_cost. Add it and the chain runs end to end instead of starting at your warehouses.
